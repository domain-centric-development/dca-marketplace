# WCAG 2.2 AA, by number

The criteria the skill's section 11 holds a page to — what a page author decides, each with its number.

- **1.4.3** text contrast 4.5:1, large text 3:1 — in both schemes, for every pair a theme could change.
- **1.4.11** non-text contrast 3:1 for what identifies a control or its state (an input's border where it is the
  only boundary, a checkbox, a focus indicator); a filled button needs it for its fill, not for an extra edge.
- **1.4.1** meaning never by colour alone.
- **1.4.4 / 1.4.10 / 1.4.12** text resizes to 200 %, the page reflows at 320 px wide without sideways scrolling
  (drawings and tables excepted), text spacing can grow without clipping.
- **2.4.7 / 2.4.11** focus always visible (`:focus-visible`, a token colour) and not hidden under a sticky bar
  (`scroll-padding`).
- **2.5.8** targets at least 24×24 px or spaced to that.
- **3.2.6** help in the same place; **3.3.1/3.3.3** errors named and how to fix them, an error summary on long
  forms; **3.3.7** no asking twice for what was entered; **3.3.8** no blocked paste, `autocomplete` on personal
  fields.
