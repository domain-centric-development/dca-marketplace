# STAGE-COMMON-26

**Never adopt a knowledge source the profile did not name** — an installed catalog may be an older vendored release;
its ids and recipes can describe a version the project does not use, and a citation makes that look verified. Say
so in your file ("`<skill>` is available but not named in the profile, so it was not used") and decide from the
project's own rules, markers and documents.
