# STAGE-COMMON-32

Running again on an answered record (asked by your stage, or `applies: <your stage>`): apply the answer and cite the id
where it landed (`Decision <id> answered <option>: …`) — the gate refuses a file without the citation and a
`## needs-human` without a record (`GATE-DECISIONS`).
