# STAGE-COMMON-8

A prompt that names one stage — *Carry out the <stage> stage* — asks for that one stage (or step).
Do it yourself in this session; do not delegate it. Do not run other stages. Read only the story and
the files its brief names as its input, and write its output file in the run folder.
