# STAGE-COMMON-24

*Review the change … from the <perspective> perspective* names the review skill, the diff, its inputs and the report
path. Apply the skill to the diff; open a whole file only where the diff's context does not carry the question.
Report in the skill's own format: `## Findings` with must-fix, should-fix and nits, each with file, line and a
one-line fix; say plainly when you found nothing. Change no other file and no code — a judge reads the reports.
