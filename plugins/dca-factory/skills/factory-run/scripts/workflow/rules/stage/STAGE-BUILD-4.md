# STAGE-BUILD-4

4. Use the project's own building blocks and conventions: its markers, its base types, its
   package layout, its error handling. Where the project ships an architecture rule suite, run it
   and take it as binding. An expected refusal takes the style the plan's `## Context` names for its
   context — returned as a case of the use case's closed result, each refusal case carrying the
   project's refusal marker, or thrown as the project's failure type — never both in one context; and
   either way **decide, then write**: every refusal comes before the first write. A failure an output
   port declares is the type its contract names, thrown by the adapter and caught by its concrete type
   in the use case, never by a base type; no incoming adapter catches a base type that would also catch
   such a failure. Which base types and which marker the project uses is its carriers' to say.
