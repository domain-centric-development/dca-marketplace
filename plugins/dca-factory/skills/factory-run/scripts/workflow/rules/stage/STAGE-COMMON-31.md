# STAGE-COMMON-31

Each option one list item `- <label>: <text>` — lowercase letter, colon, plain text; no bold, no dash after the label;
longer text on indented lines below. An answer `b` becomes option b's first line in the story, so that line is a
sentence of its own. The recommendation opens with its label.
