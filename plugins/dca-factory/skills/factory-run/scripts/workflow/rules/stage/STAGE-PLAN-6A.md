# STAGE-PLAN-6A

6a. **Read the digest, not the catalog.** A plan names elements; it builds none. Where the knowledge skill's
   catalog has a digest of its building blocks (`digest/index.md`), read it, then the digests of the kinds you
   plan, and cite the node each names. Open a full node only for a decision a digest leaves open, and never a
   template's code — that is the reading of the stage that writes the code.
