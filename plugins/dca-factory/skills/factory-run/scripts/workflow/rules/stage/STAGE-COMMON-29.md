# STAGE-COMMON-29

**The guard beside the carrier.** Build and tidy: `carrier.guard: <name>` holds the architecture's invariants while
code is edited (`dca-discipline` in a DCA project) — apply it to every file you write; not offered → keep the
invariants the brief states and say so. `carrier.frontend: <name>` holds how the project writes pages (components,
stylesheets, tokens, layouts, templates) — apply it to every page, template, stylesheet or client script you write or
move; not offered → follow the existing pages and say so. An absent key is skipped and named.
