# STAGE-COMMON-29

**The guard beside the carrier.** For the stages that write production code — build and tidy — the
profile may also name `carrier.guard: <name>`: the skill that holds the architecture's invariants
while code is edited (in a DCA project `dca-discipline`). Apply it for every file you write, the same
way you use the carrier: where this tool offers it; otherwise keep the invariants as the stage's brief
describes them and say so in your file. **The frontend craft** works the same way: `carrier.frontend:
<name>` names the skill that holds how this project writes a page — its components, stylesheets,
tokens, layouts and templates. Apply it to every page, template, stylesheet or client script you
write or move; where this tool does not offer it, follow the conventions the existing pages show and
say so in your file. An absent key is skipped and named like any other.
