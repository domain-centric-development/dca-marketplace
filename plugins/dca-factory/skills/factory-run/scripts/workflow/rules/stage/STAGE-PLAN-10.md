# STAGE-PLAN-10

10. Terms **and operations** in the criteria missing from the glossary → proposals with a one-line definition; an
   operation as `<domain word> (<code word>): <what it does to which term>`. Name use cases, commands and events from
   the code word. It comes from the glossary, the description's `## Glossary` or the story's answered assumptions; none
   gives it and the word could name more than one operation (create or add, delete or cancel) → `## needs-human`, not a
   choice. Never invent domain language silently.
