# RUN-BACKLOG-6

**When:** the factory's worker — the one `up` or the page starts — looks for what to start next

**Why:** a person waits for what they asked for, never for a story that runs; only working the backlog off on its own
is `up`'s, and `down` stops that and nothing else. The worker ends once the backlog is off and no page is open.
